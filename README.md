# E-Plant Shopping

A simple plant shopping web application built with React and Redux Toolkit.

## Features

* Browse plants by category
* Add plants to the shopping cart
* Increase and decrease quantities
* Remove products from the cart
* Calculate product subtotals
* Calculate the total cart amount
* Display the total number of items in the cart

## Technologies

* React
* Redux Toolkit
* React Redux
* JavaScript
* CSS
* Vite
* GitHub Pages

## Installation

Clone the repository:

```bash
git clone https://github.com/carlosolis2211/e-plantShopping.git
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

## Deployment

The application is deployed using GitHub Pages.

```bash
npm run deploy
```
